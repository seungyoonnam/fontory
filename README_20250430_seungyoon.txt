5) 폰트 최신/인기순 조회
■ 모든 사용자들의 공개된 폰트 목록을 탐색하고 인기순/최신순으로 정렬할 수 있다.
■ 목록의 각 항목은 폰트 이름, 게시자의 프로필 폰트 미리보기 이미지, 좋아요 버튼 등을 포함한다.
URI
/fonts?sort=latest		공개폰트 최신정렬
/fonts?sort=popular		공개폰트 인기순정렬


6) 폰트 업로드	***로그인정보 저장방식 session? jwt?
■ 나의 폰트를 타 사용자에게 공개할 수 있다.
■ 공개할 폰트를 선택한 뒤 폰트에 대한 설명을 작성하면 업로드할 수 있다.
■ 폰트를 공개할 시 서버의 요청에 의해 DB가 갱신된다.
URI
/fonts/private?userId={user_id}	로그인된 유저의 비공개 폰트 목록을 불러옴
/fonts/{fontId}/publish			폰트 설명 갱신 후 선택된 폰트를 공개로 전환



7) 유저 폰트 저장	***디렉토리구조 fontory/uploads/images, fontory/uploads/fonts
■ 모든 사용자들의 공개처리된 폰트를 다운로드할 수 있다.
■ 폰트는 TTF, OTF 두가지 형태로 다운로드가 가능하며, 다운로드한 폰트는 마이페이지에서 조회 가능하다.
■ 폰트를 저장할 시 서버의 요청에 의해 DB가 갱신된다.
URI
/fonts/{fontId}				폰트 상세페이지로 이동
/fonts/{fontId}/save			로그인한 유저가 타 유저의 폰트를 저장
/fonts/{fontId}/download/ttf	TTF 파일 다운로드
/fonts/{fontId}/download/otf	OTF 파일 다운로드


8) 폰트 좋아요 버튼
■ 모든 사용자들의 공개처리된 폰트에 대하여 좋아요를 표할 수 있다.
■ 폰트별 좋아요 개수는 5)번 ‘폰트 최신/인기순 조회’에서 인기순 정렬에 반영되며, 마이페이지에서 사용자가 좋아요를 표시한 폰트를 모아볼 수 있다.
■ 좋아요 버튼을 누를 시 서버의 요청에 의해 DB가 갱신된다.
URI
/fonts/{fontId}/like	폰트의 좋아요를 +1


13) 연습장 생성

■ 폰트 상세정보 페이지에서 연습장 생성 페이지로 이동할 수 있으며, 연습장 생성을 선택할 시 배경 이미지 및 폰트 선택창으로 이동한다.
■ 생성된 연습장은 10)나의 연습장 기록 조회 기능에서 조회할 수 있다.
■ 연습장 생성 시 서버의 요청에 의해 DB가 갱신된다.

16) 폰트 생성		**fontory/uploads/handwriting/{userId}_{UUID}.png
■ 15)번 항목에서 이미지를 등록하면 AI가 자동으로 폰트를 생성한다. 해당 폰트는 OTF, TTF 형식으로 다운받을 수 있다.
■ 사진 업로드 → 자동으로 AI 폰트 생성 → 폰트 생성 완료
■ 폰트 생성이 완료되면 폰트 이름 등 정보를 입력한 뒤 폰트가 저장할 수 있으며, TTF와 OTF 두 가지 형식으로 다운받을 수 있다.
■ 생성된 폰트는 마이페이지에서 확인할 수 있다.
■ 폰트 생성 시 서버의 요청에 의해 DB가 갱신된다.

=========Web 기능============


1) 회원 정보 조회
■ 회원 관리 페이지에서 회원 정보를 목록으로 조회할 수 있다.
■ 회원 관리 페이지에서 이름, 이메일, 전화번호, 생년월일 등 사용자들의 정보를 조회/수정/삭제할 수 있다.

2) 회원 정보 수정
■ 회원 관리 페이지에서 각 회원의 정보를 수정할 수 있다.
■ 회원 정보 수정 페이지에서 프로필 사진과 이름, 이메일, 전화번호, 생년월일 등 개인정보를 수정할 수 있다.
■ 회원 정보 수정 페이지에서 내용 수정 시 서버의 요청에 의해 DB가 갱신된다.



5) 폰트 관리
■ ‘데이터 관리’ 페이지의 ‘폰트 관리’ 메뉴에서 모든 사용자의 모든 폰트를 탐색, 삭제할 수 있다.
■ 폰트 관리 페이지는 검색창과 폰트 이름, 게시자, 미리보기, 원본 손글씨 이미지 등의 정보가 담긴 폰트 목록을 포함한다.
■ 폰트 삭제 시 서버의 요청에 의해 DB가 갱신된다.

6) 연습장 관리
■ ‘데이터 관리’ 페이지의 ‘연습장 관리’ 메뉴에서 모든 사용자가 생성 및 저장한 모든 연습장을 탐색, 삭제할 수 있다.
■ 연습장 관리 페이지는 검색창과 연습장 목록을 포함한다. 연습장 목록은 번호, 폰트이름, 글귀, 생성자, 생성일 등의 정보를 포함한다.
■ 연습장 삭제 시 서버의 요청에 의해 DB가 갱신된다.

7) 필사 문구 관리
■ ‘데이터 관리’ 페이지의 ‘필사 문구 관리’ 메뉴에서 필사 문구를 추가, 탐색, 수정, 삭제할 수 있다.
■ 필사 문구 관리 페이지는 검색창, 필사 문구 목록과 각각의 필사 문구 목록에 대해 추가/수정/삭제 기능을 제공한다.
■ 필사 문구 추가/수정/삭제 시 서버의 요청에 의해 DB가 갱신된다.

8) 필사 게시판 관리
■ ‘데이터 관리’ 페이지의 ‘필사 게시판 관리’ 메뉴에서 모든 사용자의 모든 필사 게시물을 탐색, 삭제할 수 있다.
■ 필사 게시판 관리 페이지는 검색창과 필사 게시물 목록을 포함한다. 필사 게시물 목록은 필사 게시물 정보와 삭제 기능을 제공한다.
■ 필사 게시물 삭제 시 서버의 요청에 의해 DB가 갱신된다.
